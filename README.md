# TrackTemplate validation evidence

Public storage for the bounded TrackTemplate L1 validation workload.
The repository name is retained so existing links remain valid.

On 2026-10-30 the project owner superseded the earlier private-storage and
encryption requirements and directed public handling of this workload.
No additional personal access token is required to download public inputs.

Input identities, source provenance, execution limits, recovery evidence and
independent review requirements remain unchanged. Public handling does not
assert physical-fit, production, rights, release or phase-exit acceptance.
